# 画风之间

**在 330 种画风里，找到你喜欢的那一种。**

选两张头像，看看它们之间能经过哪些画风。遇到喜欢的，点开详情，填入你想画的内容，复制提示词去生图。

浏览和获取提示词不需要 API Key，也不需要下载 AI 模型。

![330 版当前网页，桌面视图](screenshots/current-330-desktop.png)

## 怎么玩

1. **先看看。** 打开网页，查看默认路线；点击「换一组配对」试试其他组合。
2. **自己选两端。** 在「画风编目」里找喜欢的头像，点开后选择「设为起点」或「设为终点」。也可以按编号、名称或关键词搜索。
3. **沿途找画风。** 路线上的头像都能点开。你可以对照头像示例与画风参考图，也可以收藏，留在当前浏览器里下次再看。
4. **拿走提示词。** 在详情里填写主题，例如「一只在窗边晒太阳的橘猫」，点击「复制提示词」，或下载 TXT 文件。
5. **到生图工具中使用。** 粘贴提示词。如果提示词要求参考图，就点击「下载原典参考图」，将下载的图片一并上传。模型选项在「可选高级约束」里；不确定时选「其他／不确定」。

你还可以点击「分享路径」，复制包含起点、终点和资料版本的链接。**按下方方法在本机运行时，链接以 `127.0.0.1` 开头，只能在你自己的电脑上打开，发给别人无法访问。** 部署到可公开访问的网站后，才能通过该网站的链接对外分享；「分享路径」按钮本身不会把网页上传到互联网。

收藏只保存在当前浏览器，不会自动同步到其他设备。

> 这里展示的是已有画风之间的连接，不会在网页中生成图片。两端之间可能没有路线；生成效果也需要你在生图工具里实际尝试。

## 在自己的电脑上打开

目前提供本地打开方法。项目尚未提供已核验的公开体验地址。

**Windows 和 macOS 都可以使用。** 准备一台安装了 Python 3 的电脑，以及下载、解压后的完整项目文件夹。只浏览网页，不用安装 `requirements.txt` 里的开发依赖。

1. 打开项目文件夹，确认能看到 `index.html`、`data` 和 `assets`。
2. 在这个文件夹里打开终端：

   - **Windows：** 点击资源管理器地址栏，输入 `powershell` 后回车。
   - **macOS：** 打开「终端」，输入 `cd` 和一个空格，再把项目文件夹从 Finder 拖入终端窗口，按回车。

3. 根据系统输入命令并回车。

   **Windows：**

   ```powershell
   python -m http.server 5190 --bind 127.0.0.1
   ```

   **macOS：**

   ```bash
   python3 -m http.server 5190 --bind 127.0.0.1
   ```

4. 保持终端打开，在浏览器地址栏输入 [http://127.0.0.1:5190/](http://127.0.0.1:5190/)。
5. 使用完毕后，在终端按 `Ctrl+C` 关闭服务。

Windows 如果提示找不到 `python`，可以试试把命令开头换成 `py`；如果两者都不可用，请先安装 Python 3，安装时勾选添加到 PATH。macOS 如果提示找不到 `python3`，请先安装 Python 3，再重新打开终端。

**常见问题**

- **双击网页后没有图片或数据：** 按上面的方法启动服务，再从浏览器地址栏打开；不要直接双击 `index.html`。
- **提示端口被占用：** 把命令里的 `5190` 换成 `5191`，浏览器地址也改成 `http://127.0.0.1:5191/`。
- **复制按钮不可用：** 手动选中提示词复制，或下载 TXT 文件。
- **没有找到连接：** 换一个起点或终点。这表示当前画风网络没有连接这两个端点。

## 关于这 330 种画风

画风资料、分类编号与提示词规则来自 **yang0 / handraw-style**，来源版本记录在项目数据中。网页编号采用 FA–FH 分类；头像示例由本开源项目作者提供。

路径根据图片的视觉特征计算，可能受到颜色、背景和人物结构的影响，供探索与比较使用，不代表艺术史关系、审美排名或生图效果保证。

网页头像统一使用 512×512 的 WebP 图片。新增 69 张的 PNG 原图已从当前 Git 版本移除，仓库和网站部署包均使用 WebP；这次格式转换保留原有路线、收藏及旧版 330 资料的分享链接。

网页没有账号系统，收藏保存在浏览器本地，未设置主题或收藏上传接口。当前页面使用本机字体，不请求第三方字体服务。

## 给想修改或部署的朋友

网页是静态站点，不需要服务器端推理服务。你可以修改界面、替换素材，或部署到静态网站托管服务。

- 替换素材与重建路线：见 [重建指南](REBUILD.md)。
- 使用已有 Nginx 部署：见 [部署指南](DEPLOYMENT.md)。
- 英文仓库简介与标签：见 [GitHub 仓库资料](GITHUB_METADATA.md)。
- 历史模型对照：见 [实验记录](research/REPORT.md)，其中的 261 张对照属于早期实验。

检查当前 330 版数据和交互算法：

```bash
node tests/core.test.mjs
python scripts/verify.py
```

生成发布包，并检查文件范围、隐私模式和本地 Git 历史：

```bash
python scripts/package.py
python scripts/audit_privacy.py --history --archives
```

`output/style-path-explorer-website.zip` 用于静态部署；`output/style-path-explorer-source.zip` 包含公开源码。打包只收录明确列出的文件与当前素材清单，不递归打包内部研究目录、缓存或私人笔记。隐私扫描是辅助检查，不能替代人工审查。
